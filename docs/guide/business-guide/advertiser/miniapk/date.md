## 1、登录小游戏开发者平台
登录[小游戏开发者平台](https://microapp.bytedance.com/game/)
## 2、选择目标游戏
选择你所投放的游戏，点击进入【推广-广告投放】查看数据详情
## 3、查看直投数据

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/952c20c26a9745a2a6a864795b8479da)

#### 数据概览：

| **指标** | **指标口径** |
| --- | --- |
| 昨日广告消耗（元） | 昨日的直投广告总消耗（不区分是否为昨日激活用户） |
| 本月广告消耗（元） | 本月的直投广告总消耗（不区分是否为昨日激活用户） |
| 昨日新增用户数 | 昨日通过直投产生新增用户数 |
| 本月累计用户数 | 历史通过直投带来的新增用户，在本月活跃的去重用户数 |
| 昨日买量收入（元） | 昨日通过直投产生的收入（分成前） |
| 本月买量收入（元） | 本月通过直投产生的收入（分成前） |

#### 激活用户分析
> 可分析当日通过广告激活用户的转化数据

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/c8020f8115564f3abcc09aa942bcdbd8)

支持筛选各指标查看分指标数据趋势
##### **激活用户首日数据**

| **指标** | **指标口径** |
| --- | --- |
| 投放广告消耗 | 当日直投广告总消耗 |
| 激活用户数 | 当日通过信息流直投广告激活的用户数 |
| 激活成本 | 【投放广告消耗】/【激活用户数】 |
| 新增广告收入（分成前） | 当日激活用户带来的广告收入（分成前） |
| 新增内购收入（分成前） | 当日激活用户带来的内购收入（分成前） |
| 新增广告变现人数 | 当日激活用户中，产生广告变现收入的人数 |
| 新增eCPM | 当日激活用户，当日的广告变现eCPM |
| 新增广告arpu | 当日激活用户，当日的广告arpu |
| 新增付费渗透率 | 当日激活用户，有付费行为的人数/当日激活总人数 |
| 新增内购arpu | 当日激活用户，当日的内购arpu |
| 新增总arpu | 当日激活用户，当日的总arpu |
| 投放广告曝光pv | 信息流直投广告的当日曝光次数 |
| 投放广告点击数pv | 信息流直投广告的当日点击次数 |
| cpc | 每次点击计费金额 = 【投放广告消耗】/ 【投放广告点击数pv】 |
| ctr | 信息流直投广告点击率=【投放广告点击数pv】/【投放广告曝光pv】 |

##### **激活用户留存数据**

| **指标** | **指标口径** |
| --- | --- |
| 广告激活用户留存人数 | 广告激活用户在第n天的留存人数 |
| 广告激活用户留存率 | 当日激活用户在第n天的留存人数/当日激活用户数 |

##### **激活用户变现数据**

| **指标** | **指标口径** |
| --- | --- |
| ROI | n=激活用户在n日内产生的总收入（分成前）/激活当日消耗 |
| 广告ROI | n=激活用户在n日内产生的广告总收入（分成前）/激活当日消耗 |
| 内购ROI | n=激活用户在n日内产生的内购总收入（分成前）/激活当日消耗 |
| 总LTV | n=激活用户在n日内产生的总收入（分成前）/首日新增用户数 |
| 广告LTV | n=激活用户在n日内产生的广告总收入（分成前）/首日新增用户数 |
| 内购LTV | n=激活用户在n日内产生的内购总收入（分成前）/首日新增用户数 |

##### 变现 ROI：

| **指标** | **指标口径** |
| --- | --- |
| 总ROI 1 | 激活用户首日产生的总收入/激活当日直投消耗 |
| 总ROI n | 激活用户n日内产生的总收入/激活当日直投消耗 |
| 广告ROI 1 | 激活用户首日产生的广告收入/激活当日直投消耗 |
| 广告ROI n | 激活用户n日内产生的分成前广告总收入/激活当日直投消耗 |
| 内购ROI 1 | 激活用户首日产生的分成前内购收入/激活当日直投消耗 |
| 内购ROI n | 激活用户n日内产生的分成前内购收入/激活当日直投消耗 |

#### 历史买量累计分析
> 可分析历史通过广告激活用户（包含当日激活用户）累计在当日的转化数据

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/e0aac1c5e0014459aa7cc556eff89853)

##### 买量激活用户累计数据

| **指标** | **指标口径** |
| --- | --- |
| 当日总收入 | 分成前当日小游戏单日广告收入+内购总收入 |
| 活跃广告收入 | 分成前当日小游戏活跃用户产生的广告收入 |
| 活跃内购收入 | 分成前当日活跃用户产生的内购收入 |
| 游戏加载次数 | 游戏启动加载的次数 |
| 活跃用户数 | 小游戏的活跃用户数 |
| 变现广告展示数pv | 小游戏广告变现的广告播放的次数 |
| ecpm | 每千次广告展示收入 |
| 人均游戏时长 | 当日人均游戏时长 |

## 4、查看微端投放数据
#### **1）实时数据查询：**
支持按账户 ID 和计划 ID 查询投放的实时数据，实时观察投放效果
> 注意：不支持查询从今天算起超过 31 天的账户 ID/计划 ID 数据，请开发者及时跟进保存

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/img1681373971181)

| **指标数据展示（以混合变现游戏为例）** |  |
| --- | --- |
| 指标 | 定义 |
| 账户/计划ID | 游戏在信息流投放的账户/计划ID |
| 日期 |  |
| 付费人数 | 当日完成付费的用户数，多次付费不会重复计数 |
| 总付费次数 | 当日用户完成付费的总次数 |
| 平均付费金额 | 当日总付费金额/当日付费用户数 |
| 广告LTV X（X=0、1、2、3、4、5、6、7、15、30） | 当日激活用户在X日内的广告变现金额 |
| 内购LTV Y（Y=0、1、2、3、4、5、6、7、15、30） | 当日激活用户在Y日内的内购金额 |

#### **2）离线数据查询**：
支持按渠道号查询投放的天级数据，可根据投放的端名称筛选任务数据

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/d3bf649697d44ed0bcc5f98e003de40a)

##### 关键指标：

| **指标数据展示（以混合变现游戏为例）** |  |
| --- | --- |
| 指标 | 定义 |
| 日期 |  |
| APP | 信息流投放的宿主端 |
| 去重DAU | 当日活跃用户数，按设备id去重 |
| 新增用户 | 当日新增用户数 |
| 人均使用时长（s） | 当日总游戏时长/当日活跃用户数 |
| ARPU | 当日总收入/活跃用户数 |
| ARPPU | 当日内购收入/付费用户数 |
| 单日总收入 | 当日广告收入+内购收入 |
| 广告LTV X（X=1、2、3、4、5、6、7、15、30、60、90、120） | 当日激活用户在X日内的广告变现金额 |
| 内购LTV Y（Y=1、2、3、4、5、6、7、15、30、60、90、120） | 当日激活用户在Y日内的内购金额 |

##### **收入指标：**

| **指标数据展示（以混合变现游戏为例）** |  |

| 新增广告收入 | 当日新增用户广告收入 |
