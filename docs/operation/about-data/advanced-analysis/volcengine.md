面向小游戏开发者，结合小游戏自身业务和生态特点，增长分析具备一套有效的指标体系和场景化分析模型，满足开发者对玩家及业务增长方面进阶的数据分析及决策的需求：

核心能力：

（1）多端数据打通

可基于用户 ID 将位于不同平台的小程序、APP、H5 甚至服务端的用户及行为数据打通，帮你洞察用户的全景轨迹

（2）多种深度分析

通过分布分析、LTV 分析、路径分析、归因分析、SQL 查询等，从更多角度洞察用户行为的真实规律

（3）私域数据导出

通过 OpenAPI 可导出不同形式的数据，包括明细数据，查询结果等
