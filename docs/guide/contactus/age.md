## 一、背景
根据《未成年人保护法》、《防止未成年人沉迷网络游戏的通知》、《网络游戏适龄提示标识》等法规和标准以及监管部门要求，为了给未成年游戏用户和其监护人准确的游戏适龄提示，游戏应根据不同年龄段未成年人的特点、综合考虑适龄的游戏类型与游戏功能，对游戏进行评估，确定游戏适用的年龄段，选择对应的游戏适龄提示标识和提示说明，网络游戏已于 2021 年 6 月 1 日全面实施“适龄提示”。
## 二、适龄范围
《网络游戏适龄提示》将未成年人游戏适龄的范围划分为 3 个阶段，即**8+、12+、16+**
### 8+
游戏画面需满足整体简约、可爱卡通，游戏内容应该简单友好不复杂，不存在复杂的背景和游戏人物关系。游戏内可以出现简单肢体操作和思维判断，也可以设置少量的对抗性玩法，或存在少量好友合作。
需要注意的是，8+游戏不可以出现陌生人自由式交流互动场景，包含但不限于文字，语音，图片等任何表达形式。

## 三、适龄分段说明
![](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/适龄-8124172234477578.PNG)
具体可参考：

|  | 参考维度 | 参考说明 |
| --- | --- | --- |
| **8+** | 画面表现 | 游戏画面整体简约，Q版可爱卡通风格，手绘画面为主 |
| 内容要素 | 无基于历史和现实事件的改编的游戏，整体玩法内容单一，无复杂性简单易上手。游戏内部元素整体简单友好，设定情节玩法简单，无复杂的背景和游戏人物关系，无需过多思考即可 |
| 不可与陌生人团队合作，内容需简单易懂，如需好友助力才可完成，可少量好友团队合作 |
| 竞技与对抗 | 简单的肢体操作和思维判断，普通点击、前进、左右滑动、跳跃等，如体育赛跑、棋类竞技 |
| 游戏可以存在剧情需要的少量对抗设置 |
| 社交系统 | 陌生人：游戏中不可出现与陌生人一对一或一对多的自由式交流互动场景，包含但不限于文字，语音，图片等任何表达形式 |
| 好友：游戏中可存在简单好友交互系统，如好友点赞、送体力和助力等行为，禁止出现文字，语音，图片等互动交流行为 |
| **12+** | 同时不满足16+和8+的判定标准，即属于12+ | |
| **16+** | 画面表现 | 游戏人物场景注重细节刻画，写实主义 |
| 内容要素 | 1、拟真恋爱养成体验，故事上夸张程度低，写实度高，具有对现实世界的恋爱进行指导的功能，存在恋爱、结婚、生子系统。 2、名称含有恋爱、情侣 |
| 注重角色塑造恐怖感，气氛烘托和心理暗示，无论是其恐怖场景的营造和桥段设计身临其中的恐怖氛围。 |
| 竞技与对抗 | 游戏具有丰富的战斗系统，极其强烈的战斗竞技场面，或现实世界可进行模仿，存在玩家与魔兽对抗、玩家间等其他的PK活动，团队协作，用户之间的互动。 |

## 三、适龄提示说明文案 tips
在游戏的加载页中，会展示当前游戏对应的“适龄图标”，点击适龄图标后可打开弹窗，查看当前游戏的“适龄说明”内容。开发者可以前往开发者平台中的基础设置页面，对自己的游戏[适龄说明文案](https://microapp.bytedance.com/game/tt0f3c79819007fa4b/setting/rightAge)进行修改。

|  |  |
| --- | --- |

设置页中，已经为大家提供了模板的预览效果，开发者在编辑文案的时候，可以看到已填写的内容在整体说明文案的状态，以便更好地衔接上下文。但在以往的审核中，上下文语句不通顺和存在错误的标点符号反而占据了拒绝场景中的最高比例。
![](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/tips3-5538464551922972.png)
填写说明文案有几个要点：
1.不要在说明文案中使用如“/”、“|”、“空格”或其他特殊字符，也不要在句末输入任何标点符号。
2.注意填写的文案语句通顺、语义详实，不使用错别字、繁体字或者其他复杂外语，也要注意断句时使用正确的标点进行断句，不要在未完整说完一句话时使用句号。
3.游戏内容需要与所填写的游戏类型、游戏背景、游戏剧情、游戏玩法、游戏主体以及游戏价值的描述可对应，不可出现不相关内容。
4.游戏的玩法和剧情不是游戏价值，游戏价值需要有或宏观或具象的体现。
5.社交系统和婚恋系统需要符合游戏具体情况，不可随意填写。
