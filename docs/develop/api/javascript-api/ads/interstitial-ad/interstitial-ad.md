插屏广告实例。通过[tt.createInterstitialAd](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/ads/tt-create-interstitial-ad)方法获取。
## 属性说明
| 属性名 | 类型 | 说明 |
| -------- | -------- | ------------------------ |
| show | Function | 显示插屏广告 |
| load | Function | 加载插屏广告 |
| destroy | Function | 销毁插屏广告 |
| onLoad | Function | 监听插屏广告加载事件 |
| offLoad | Function | 取消监听插屏广告加载事件 |
| onError | Function | 监听插屏错误事件 |
| offError | Function | 取消监听插屏错误事件 |
| onClose | Function | 监听插屏广告关闭事件 |
| offClose | Function | 取消监听插屏广告关闭事件 |
