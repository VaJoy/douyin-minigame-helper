MediaElementAudioSourceNode 表示由 Audio 对象组成的音频源。它是一个 AudioNode，充当音频源，MediaElementSourceNode 没有输入，只有一个输出。可以通过[AudioContext.createMediaElementSource](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/media/audio/AudioContext/audio-context-create-media-element-source) 创建。
## 属性
> 从其父类 AudioNode 继承属性
| 属性名 | 类型 | 读写特性 | 描述 |
| ------------ | ------ | -------- | ------------------------- |
| mediaElement | object | 只读 | 节点输入的 Audio 对象元素 |
## Bug & Tip
暂无。
