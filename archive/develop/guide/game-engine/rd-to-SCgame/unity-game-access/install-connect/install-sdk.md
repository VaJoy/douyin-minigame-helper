## 如何安装 TTSDK
### 安装 BGDT package
下载链接：[BGDT（Byte Game Develop Tools）](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/BGDT-handbook/install)[ ](https://lf3-stark-cdn.bdgp.cc/obj/ide-updateserver-bytegame/bgdt/com.bytedance.bgdt/3.0.250/com.bytedance.bgdt.unitypackage)

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/73e7c59f60bf407b80caffb7a44c2cf8)

> 注：导入了该工具，登录后，右上角应该显示 `cp`，如果不是请完全删除原有的 BGDT 再重新安装。

### 安装 TTSDK 包
选择 `TTSDK` , 选择最新版本安装。

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/6ffebaf0d4f040dcbd520d095a8ad1ac)
