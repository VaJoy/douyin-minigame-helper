## 二、进阶玩法

**可以通过排行榜去做一些游戏内运营活动，如 “刺激用户冲榜” 有奖，持续刺激用户的活跃与留存，届时直接根据榜单数据记录下用，并通过榜单进入用户个人主页，私信用户发奖即可，下面是一个活动例子：**

1.**活动时间**：活动时间 1-3 天

2.**榜单逻辑**：建议设置成总榜（若天榜或周榜，建议提前在刷新日期前做好截图）

3.**活动奖励**：活动期间/活动期间每天全服前 xx 名，赠送道具奖励（发放兑换码），或 x名 - xx 名是什么奖励，以此类推

4.**活动引导**：每局结束后需要提示玩家，当前分数，排名（只提示 1000 名内，未进榜单的用户，提示他继续加油，冲进榜单领取奖励；分数在 1000 名内的用户，告知排名及可获得奖励，并激励再次游戏获得更好成绩）

5.**发奖操作**：日榜：每天 23:00 之后，锁榜，按照排行榜玩家名单发放奖励，也可以等活动周期结束统一发放；总榜：活动周期结束后，按照排行榜玩家名单发放奖励 \*以上所有数值/时间，均可自行定义

6.**实验数据效果**：提升明显 （活动期间及日常数据变化：基于历史数据及活动期间数据对比）

## 三、发现的问题和迭代计划

**我们也持续发现开发者反馈的一些问题，这边也给出了修复方案与后续计划，若有更多问题，也欢迎随时加入技术交流群进行反馈：**

|  |  |
| --- | --- |
| **问题** | **解决思路** |
| 需要自定义UI的时候，在保密环境内，需要对比用户本局成绩是否高于历史成绩时，若高于则更新数据，现在在保密环境内只能获取信息展示，无法写入信息，可能导致排行又问题 | 【已解决】23.5版本已支持在保密环境内写入数据，可以迂回满足比较历史成绩后决定是否更新数据的诉求    后续开发者可以设置，是否要做大小过滤（即数据小于数据库内的数据则不写入） |
| 需要能够直接获取当前登录用户的排行与分数信息，做「上榜有奖」、「成绩对比写入」等游戏内的特殊功能 | 【待规划 P0】有价值和强诉求，后续可以开放支持 |
| unity游戏为什么不支持排行榜功能 | 【已解决】unity游戏同步支持中了，预计232.5版本支持 |
| 希望支持多个榜单，有榜单分组的功能，这样游戏可以实现更多维度的排行（如 等级、战力、装备排行） | 【待规划 P0】有价值和强诉求，后续可以开放支持，能够给数据分配分组标识 |
| 希望官方能够提供更多维度的排行榜，目前好友榜信息不够 | 【待规划 P1】有价值和强诉求，后续可以开放支持（地区、性别等） |
| 能不能设置几个虚拟机器人放在好友榜里，让用户也有挑战冲击的欲望，现在可能用户的好友比较少 | 【暂不受理】需要下来确认实现方案 |
| 现在调用很便捷，但希望官方可以迭代排行榜组件，让用户做更多邀请的动作，包括榜单刷新也希望可以告知用户让用户一直玩 | 【待规划 P0】有价值和强诉求，后续可以开放支持，如 “夸夸”功能，可以一键为高分榜单用户进行夸赞 |
