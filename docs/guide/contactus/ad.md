## **一、阻碍或诱导用户误触广告**
### 1.快速点击导致误触
**审核规范：**小游戏不得存在连续/快速点击设置，导致用户误触广告。
**常见拒绝场景：**

| ❌在游戏过程中，点击【快速点击】按钮，无任何感知，触发突然出现的广告按钮 |
| --- |
|  |

**修改指引：**当设置有明确要快速点击场景时，设置广告按钮建议给到用户明确感觉，或者避免将广告按钮设置在容易误触的区域。
### **2.自动调起广告**
**审核规范：**小游戏中严禁设置种种障碍，阻碍用户取消看广告/诱导用户误触广告/自动调起广告。
**常见拒绝场景：**

| ❌在游戏过程中，无任何感知，突然出现广告 |
| --- |
|  |

**修改指引：**设置广告需给用户有提前的感知和选择，不可以在未知情况下点击或直接出现广告。
## 二、icon 标识不规范
### **1.标识非平台样式**
**审核规范：**小游戏触发广告的按钮/背景上，未统一使用平台规定的视频广告标识，样式不符合平台要求。
**常见拒绝场景：**

| ❌游戏过程中，点击【免费钻石】/【加速】按钮，使用非平台规定的广告标识 |
| --- |
|  |

**修改指引：**使用平台规定的视频广告标识（[官方标识下载](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/microapp.pdf)）
### **2.样式不符合要求**
**审核规范：**小游戏触发广告的按钮/背景，均未使用平台规定的视频广告标识，样式不符合平台要求。
**常见拒绝场景：**

| ❌小游戏中广告按钮是描边样式，仅线条勾勒，刻意弱化标识感知 |
| --- |
|  |

### **3.广告标识过小**
**审核规范：**小游戏触发广告的按钮/背景上，未统一使用平台规定的视频广告标识，大小不符合平台要求。
**常见拒绝场景：**

| ❌小游戏带有广告按钮的icon标识过小，影响识别 |
| --- |
|  |

**修改指引：**按钮设置要有强感知，广告标识和文案需清晰展示。
### **4.色彩对比不强，感知不明显**
**审核规范：**小游戏触发广告的按钮/背景上，未统一使用平台规定的视频广告标识，色彩不符合平台要求。
**常见拒绝场景：**

| ❌小游戏广告按钮颜色与背景色一致，感知不明显 |
| --- |
|  |

**修改指引：**按钮设置需有强感知，广告标识颜色和背景色需有明显对比度。
### **5.标识的位置没有在正确的地方**
**审核规范：**小游戏触发广告的按钮/背景上，未统一使用平台规定的视频广告标识，位置不符合平台要求。
**常见拒绝场景：**

| ❌小游戏中广告按钮和文案在同一水平线时，位置需在文案左侧对齐 |
| --- |
|  |

**修改指引：**按钮设置时，icon 要置于文案左侧。
## 三、不看广告按钮不规范
### **1.不看按钮为字体样式**
**审核规范：**小游戏中禁止使用字体样式作为广告按钮取消方式。
**常见拒绝场景：**

| ❌“点击领取”非按钮样式 |
| --- |
|  |

**修改指引：**取消观看广告按钮需与触发广告按钮一致，取消观看广告不能单独以字体形式出现。
### **2.不看按钮延迟出现**
**审核规范：**小游戏中看/不看广告领取按钮，必须同时出现。
**常见拒绝场景：**

| ❌小游戏中取消广告按钮【重新开始】延迟出现 |
| --- |
|  |

**修改指引：**取消观看视频按钮与触发广告按钮要同时出现。
### **3.不看按钮过小**
**审核规范：**小游戏中看/不看广告领取按钮，必须大小一致。
**常见拒绝场景：**

| ❌小游戏中取消广告按钮【重玩】与广告【直接跳过】大小不一致 |
| --- |
|  |

**修改指引：**取消观看视频按钮需与触发广告按钮大小一致，不能过小。
### **4.不看按钮未邻近展示**
**审核规范：**小游戏中看/不看广告领取按钮，必须邻近显示。
**常见拒绝场景：**

| ❌游戏中，看广告【复活】与不看广告【暂时不用】相隔较远 |
| --- |
|  |

**修改指引：**看广告按钮与不看按钮放在一起，且大小一致。
### **5.默认勾选了看视频按钮**
**审核规范：**小游戏中看/不看广告领取按钮，不可默认设置选择观看。
**常见拒绝场景：**

| ❌小游戏中可选择的【再来一份】按钮是默认选中的，进入该板块默认需要看视频领取 |
| --- |
|  |

**修改指引：**看广告的选择需要给用户，不能直接默认看广告。
## 四、广告页及插屏广告
### **1.广告页不可遮挡重要操作按钮**
**审核规范：**广告页遮挡重要功能按钮，不符合平台要求。
**常见拒绝场景：**

| ❌广告页遮挡了发型操作区域，导致用户无法进行选择 |
| --- |
|  |

### 2.主场景不可出现广告页
**审核规范：**小游戏主场景存在广告页，不符合平台要求。
**常见拒绝场景**：

| ❌广告页在游戏主场景出现，遮挡操作 |
| --- |
|  |

### 3.插屏广告打断游戏进程
**审核规范**：插屏广告打断游戏进程，不符合要求。
**常见拒绝场景**：

| ❌开始游戏进入主场景，在游戏过程中弹出插屏广告 |
| --- |
|  |

**修改指引**：插屏广告不要出现在主场景，可以出现在结算页、皮肤商店页面等。
## 五、广告奖励相关问题
### 1.完整看广告未获得奖励
**审核规范**：小游戏观看完整广告后无法获得对应奖励，不符合平台要求。
**常见拒绝场景**：

| ❌广告观看完毕收益符实-完整观看广告后，必须获得文案标明奖励，不得少给奖励或者奖励不符，进入游戏不会扣除金币， 游戏内观看”五倍广告“后金币显示“3296”，实际应显示“800+624*5=3920”，奖励未获得预期 |
| --- |
|  |

### 2.未完整看广告获得奖励
**审核规范**：未完整观看广告，即获得奖励，不符合平台要求。
**常见拒绝场景：**

| ❌广告观看完毕收益符实-未完整观看不可提前给予奖励，无体力时，看激励视频广告“开始游戏”，中途取消依然获得奖励 |
| --- |
|  |

### 3.视频广告点击即得
**审核规范**：视频广告点击即得，不符合平台要求。
**常见拒绝场景：**

| ❌奖励功能文案必须明确展示且保证广告观看收益 |
| --- |
|  |

### **4.广告次数，奖励未明确展示**
**审核规范：** 出现需多次观看广告才能获取一次奖励的行为，不符合平台要求。
**常见拒绝场景 1**：

| ❌游戏内需观看2次广告才可解锁”提示1“；未前置告知用户 |
| --- |
|  |

**修改指引：**看一次广告需获得一次预期奖励，若存在需多次看广告才可获得奖励的情况，可以前置用文案注明。
**常见拒绝场景 2**：

| ❌点击【观看视频】按钮前，无任何感知，不清楚在广告播放完毕会获得什么内容 |
| --- |
|  |

**修改指引：**对于奖励应做到前置文案提示可以点击出现弹窗提醒，或者按钮进行明确展示。
### **5.广告影响游戏结果**
**审核规范：**观看广告，打断游戏进程，不符合平台要求。
**常见拒绝场景：**

| ❌游戏中有倒计时，观看广告获得提示，广告过程中游戏倒计时未暂停，仍在继续计时 |
| --- |
|  |

**修改指引：**观看广告，不可对游戏产生负向影响，可以采用暂停、倒计时、无敌时间等方式使观看视频前后无变化。
### 6.广告设置无意义
**审核规范：**小游戏内部分按钮设置无意义广告，不符合平台要求。
**常见拒绝场景：**

| ❌在游戏中，点击【免费复活】需观看广告后复活游戏，点击【取消】也可以重新开始游戏。属于看视频广告重新开始，不观看也可重新开始 |
| --- |
|  |

**修改指引：**设置需观看广告后获得的相关奖励，不能与不看广告获得的奖励相同，观看广告奖励需与直接获得奖励形成区别。
