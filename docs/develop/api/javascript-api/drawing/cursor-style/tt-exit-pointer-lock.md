基础库 3.54.0 开始支持本方法，这是一个**同步**方法。
解除锁定鼠标指针，仅适用于 PC 平台用

## 示例代码
```js
tt.exitPointerLock();
```

| 错误码 | 错误信息 | 处理建议 | 版本 |

## 使用限制
只支持 PC 端使用该能力
