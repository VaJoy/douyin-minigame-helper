##

## 语法

```js
BannerAd.onError(callback)
```
基础库 1.3.0 开始支持本方法，这是一个**同步**方法。
绑定 error 事件的监听器。 广告组件拉取广告素材时如果发生错误，会触发 error 事件的监听器。

## 示例代码
```js
bannerAd.onError(({ errorCode, errMsg }) => {
   console.log(errorCode, errMsg)
})
```
