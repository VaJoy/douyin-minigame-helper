> ⚠️ 注意
> 基础库 1.12.0 开始支持
> 场景值持续扩充中，本文档将不定期更新，最新日期：20261010
> 场景值不是必定有值，特殊场景如审核可能为空，开发者需要做好空值的兼容
> *若出现未标注的场景值可能是上报有误或不再维护场景
场景值标识着小游戏的入口位置。每个场景值的构成都可以分为两部分，分别是场景值前缀和场景ID。场景值遵循以下的构成：

```text
场景值=场景值前缀+场景ID

示例：021001 = 02（抖音） + 1001（侧边栏入口）
```

### Bug&Tip
- 对于小游戏，可以在 [tt.getLaunchOptionsSync](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/system/lifecycle/tt-get-launch-options-sync) 获取上述场景值。
- 如果要判断小游戏来源，使用场景值后四位判断即可。因为同一个场景值也会对应多个情况，这里只是列举场景值的主要含义。
- 后续将在多场景逐步开放其他合作方宿主能力，不建议限定宿主端做判断，可只针对场景值后缀做限制。
