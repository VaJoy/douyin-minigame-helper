### 一、录屏数据

|  |  |
| --- | --- |
| **数据指标** | **说明** |
| 点击发布录屏次数 | 发起录屏并录屏成功的次数 |
| 点击发布录屏人数 | 发起录屏并录屏成功的设备数 |
| 点击发布录屏率 | 启动用户中发布录屏成功的占比（点击发布录屏人数/总启动用户数） |
| 录屏成功发布率 | 点击发布录屏的总次数中，成功发布的次数占比（成功发布录屏次数/总发布录屏数） |
| 人均成功发布视频数 | 每个用户发布录屏的平均数量（总录屏发布数/总启动用户数） |

### 二、互推数据

互推资源位功能相关说明：[小游戏互推能力](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/ability/gain-user/recommended)

|  |  |
| --- | --- |
| **数据维度** | **说明** |
| 互推位 | 指互推资源位中对应的九宫格、四宫格、单格子 |
| 导量来源 | 指通过互推位为本游戏带来用户的游戏 |

|  |  |
| --- | --- |
| **数据指标** | **说明** |
| 导入-活跃用户数 | 筛选时段内来自其他游戏互推位导入本游戏的去重活跃用户数 |
| 导入-新增用户数 | 筛选时段内来自其他游戏互推位导入本游戏的去重新增用户数 |
| 导出-活跃用户数 | 筛选时段内从本游戏互推位导给其他游戏的去重活跃用户数 |
| 导出-新增用户数 | 筛选时段内从本游戏互推位导给其他游戏的去重新增用户数 |
| 导入用户人均停留时长 | 导入用户停留在小游戏页面的总时长，即时段内所有导入用户总停留时长 / 总活跃人数 |
