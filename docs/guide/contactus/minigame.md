## 一、交互按钮
**审核规范：**

1. 页面按钮不可重叠、不可直接操作下层图层按钮，影响游戏进程。
2. 进入游戏多级页面均需有返回方式
3. 小游戏按钮功能需与描述相符
4. 进入游戏不可同步未知进度

**拒审关键词：**
[游戏逻辑] 在某页面可操作下级页面，影响游戏进程，不符合平台要求
[游戏逻辑] 小游戏按钮功能与描述不符
[游戏逻辑] 小游戏无法返回首页，不符合平台要求
[游戏逻辑] 游戏同步未知进度，不符合平台要求
### 1.图层重合
**常见拒绝场景：**

| ❌上下两级按钮重合，且易导致误触 | |
| --- | --- |
|  |  |

**接受场景：**当按钮清晰展示在下一图层，不会误触可接受。

| “进入游戏”与“空杯”按钮  分别清晰展示在上下两个图层，  且不会误触 | 上级页面“双倍领取”按钮与  下级页面“增加容量”“跳过本关”按钮  清晰展示，不会误触 |
| --- | --- |
|  |  |

### 2.返回首页
**常见拒绝场景：**当首页有重要板块时，小游戏无法返回首页。

| ❌首页有不同模式的内容，属于重要板块，  观看广告复活和重新开始都无法返回首页 | ❌首页有商城板块，属于重要板块，  但无论成功或失败，都无法返回首页 |
| --- | --- |
|  |  |

### 3.未知进度
**常见拒绝场景：**首次进入游戏，存在已有游戏进度。

| ❌首次进入游戏就自动完成了部分任务 | ❌首次进入游戏，就自动解锁了部分关卡 | ❌首次进入游戏，星星就同步数颗 |
| --- | --- | --- |
|  |  |  |

### 4.按钮效果
**常见拒绝场景：**按钮标识和实际效果不同。

| ❌点击视频获得提示，实际掉起录屏 | ❌点击第“19”关，实际进入的第“10”关 | ❌点击下一关按钮，实际实现的继续游戏的功能 |
| --- | --- | --- |
|  |  |  |

## 二、奖励相关
**审核规范：**

1. 声明的功能模块必须要实现，游戏内获取奖励不可少于实际标明
2. 不可重复观看广告获取多倍奖励

**拒审关键词：**
[游戏逻辑] 游戏内观看视频广告重复获取奖励，不符合平台要求
[游戏逻辑] 游戏奖励无法核实，不符合平台要求
### 1.奖励获得
**常见拒绝场景 1：**游戏奖励未获得。

| ❌开宝箱后钻石奖励未获得 | ❌观看视频并未获得道具 | ❌观看视频未获得三倍奖励 |
| --- | --- | --- |
|  |  |  |

**常见拒绝场景 2：**游戏奖励未展示。

| ❌领取的“玉”奖励，但游戏中并未该奖励的展示，无法感知 | ❌获得了金币奖励，但整个游戏中都没有金币的展示，无法感知 | ❌开宝箱获得了钻石奖励，但游戏中只有金币的展示，并无钻石展示 |
| --- | --- | --- |
|  |  |  |

**接受场景：**奖励可多得，不可少得。

| 多获得了金币奖励，可接受 |
| --- |
|  |

### 2.特殊奖励
**常见拒绝场景：**游戏逻辑上只能获得一次的奖励，不可允许用户重复获取。

| ❌过关的金币奖励为特殊奖励，  只可允许用户观看视频获得一次多倍 | ❌过关的金砖奖励为特殊奖励，  只可允许用户观看视频获得一次多倍 |
| --- | --- |
|  |  |

**接受场景：**游戏逻辑上可获得多次的奖励，允许用户重复获取。

| 无需通关固定出现在游戏中的奖励，可以设置重复观看视频获得 | |
| --- | --- |
|  |  |

### 3.单倍奖励
**常见拒绝场景 1：**单局游戏通关，结算页却要求看广告才可获得单倍奖励，恶意设置视频广告。

| ❌正常过关奖励需要观看视频才可获得 |
| --- |
|  |

**常见拒绝场景 2：**每日任务板块，已经达到任务条件，不可设置任务奖励需看广告获得奖励。

| ❌任务奖励却还要观看视频才能获得 |
| --- |
|  |

**接受场景 1：**可存在分享/看广告双倍领取途径。

| 可设置观看视频或分享录屏获得多倍奖励 | |
| --- | --- |
|  |  |

**接受场景 2：**观看视频广告补签或提前签到，可接受。

| 可设置观看视频补签或提前签到 |
| --- |
