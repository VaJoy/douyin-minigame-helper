| 数据指标 | 说明 |
| --- | --- |
| 1 天后留存率 | 日期当天的新增用户（活跃用户），在次 1 日又继续使用的比例 |
| 3 天后留存率 | 日期当天的新增用户（活跃用户），在次 3 日又继续使用的比例 |
| 14 天后留存率 | 日期当天的新增用户（活跃用户），在次 14 日又继续使用的比例 |
| 30 天后留存率 | 日期当天的新增用户（活跃用户），在次 30 日又继续使用的比例 |
