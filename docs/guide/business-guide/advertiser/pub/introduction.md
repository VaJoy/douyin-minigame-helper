「巨量星图 x 游戏发行人计划」为巨量星图官方游戏内容营销聚合平台，小游戏开发者通过「 巨量星图 x 游戏发行人计划」发布游戏推广任务，抖音创作者接单创作视频，视频自带小游戏锚点，帮助游戏增加抖音平台游戏内容量，提高游戏规模，助力精品小游戏发展。
1、**进入方式：**抖音 iOS/ 安卓 直接搜索「星图 x 游戏发行人计划」，选择小程序进入；

| 抖音搜索  「星图x游戏发行人计划」 | 进入「星图x游戏发行人计划」页面 | 任务列表页 |
| --- | --- | --- |
|  |  |  |

**2、资源概况：**目前「巨量星图 x 游戏发行人计划」月均消耗过千万，累计承接近千个游戏任务发行需求，覆盖 MCN &散人（非机构）总共超过 10w 名作者；
**3、作者情况**：

- 机构数量：近百家MCN机构；
- 机构类型：覆盖目前抖音绝大部分MCN机构，如游戏行业TOP机构「畅玩文化」「薇龙文化」「华星璀璨」「巨芯互娱」等，如泛娱乐行业TOP机构 「无忧传媒」「愿景娱乐」；定向寻找机构前置视频预埋，以优质视频引导整体任务走向；
- 非机构达人数量：聚拢近6W非机构达人；针对达人进行精细化运营，针对达人类别&视频风格进行分群维护，针对优质达人进行定向培训；
- 非机构达人类型：非机构达人类型多样，达人视频创意多，易沟通；可迅速聚拢大量视频，提升视频爆款产出概率；
- 纵向覆盖多垂类：含音乐，舞蹈，二次元，颜值，泛娱乐等。
