开发者广告收入结算费率、结算周期、支付方式公示如下：
**一、广告收益**
（1）投广场景（微端广告和直投广告）：
收益比例：开发者可获得游戏所产生的广告收入90%的现金收益。
（2）非投广场景：
收益比例：开发者可获得游戏所产生的广告收入60%的现金收益。

**开发者收益计算公式及税点：**
（1） 如果开发者能够提供增值税专用发票，且增值税率不低于 6%
开发者收益（即价税合计额）=可分配收益 X 收益比例
（2）如果开发者能提供增值税专用发票，但是增值税税率低于 6%
开发者收益（即价税合计额）=可分配收益/(1+6%) X 收益比例 X (1+增值税税率)
（3）如果开发者为个人开发者
开发者收益（即价税合计额） = 可分配收益/(1+6%) -个人所得税

**二、结算周期与支付方式**
- 开发者结算单分为半月结与日结。已申请开通日结权益的开发者，系统会在T+2自动推送小游戏日结收入明细；非日结的收入为半月结算，通常分别在当月15号起和当月底的T+4工作日，自动推送小游戏半月结收入明细（周末或节假日将延期至工作日推送，以实际系统推送时间为准）。若开发者对结算数据存在异议，应当最晚在【10】个工作日内提出，逾期则自动视为开发者确认无误，平台将按照开发者最终确认的金额代扣代缴税费（如有）后支付至开发者提交的银行账户中。
- 如开发者对结算数据无异议，企业开发者应在【15】个工作日内将与结算金额一致的合格增值税专用发票邮寄给平台，平台将在收到合格发票之日起【30】个自然日内将开发者应得款项通过银行转账方式转至其提供的银行账户中。结算周期受第三方服务效率、系统对账及结算周期、银行转账时长、网络环境、系统环境等因素影响，如开发者不提供发票或提供不合格发票或不及时提供发票，平台有权不支付或相应延迟支付。
更多结算相关说明请见[《小游戏结算使用指南》](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/business-guide/revenue/introduction/douyin-games-guide)
