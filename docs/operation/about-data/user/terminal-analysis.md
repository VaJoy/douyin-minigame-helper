## 一、终端与机型分布

- 终端作为用户运行应用的载体，背后蕴藏着丰富的用户信息。分析用户品牌分布、设备型号分布、联网方式构成等，对于运营、产品和研发工作都十分必要。
- 查看新增或活跃用户使用的设备机型分布，可区分不同 app 进行查看，数据从高到低进行排序，仅展示 top10 机型，右上角可导出当前展示数据。
