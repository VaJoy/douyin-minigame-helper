## 任务数据
### 任务列表

| **指标** | **指标口径** |
| --- | --- |
| 买量活跃用户数 | 任务带来的参与计费的买量用户数（短视频只统计发布七日内，直播间只统计开播时间内） cpa任务：当天首次通过该直播间进入小游戏的用户 cpa+cps任务：当天首次通过该直播间进入小游戏的付费用户才计费，该用户后续7日的付费数据均参与计费（包含当日）；如果当天用户在非首次进入直播后付费，仅对cps部分计费和结算 如果该用户在被直播转化前已被其他短视频/直播绑定（处于7日计费周期内），则不参与当前直播间计费结算 如果该用户历史已被该游戏通过广告投放转化为激活用户，则不参与计费 |
| 买量广告收入 | 直播带来的广告分成后收入，但包含达人分成（短视频只统计发布七日内，直播间只统计开播时间内） cpa任务：cpa当天首次通过直播进入小游戏的用户，在当次进入游戏后产生的广告分成后收入，包含需达人分成收入 如用户第一次通过直播进入小游戏，第二次通过其它非直播场景（如首页侧边栏、个人主页）进入游戏，则第一次计费，第二次不计费 cpa+cps任务：当天首次通过该直播间进入小游戏的付费用户才计费，该用户后续7日的付费数据均参与计费（包含当日）；如果当天用户在非首次进入直播后付费，仅对cps部分计费和结算。 如果该用户在被直播转化前已被其他短视频/直播绑定（处于7日计费周期内），则不参与当前直播间计费结算 如果该用户历史已被该游戏通过广告投放转化为激活用户，则不参与计费 |
| 买量内购收入 | 直播带来的广告内购收入（原始流水），包含达人费用和内购渠道费 cpa任务：cpa当天首次通过直播进入小游戏的用户，在当次进入游戏后产生的内购流水，包含需达人费用部分 如用户第一次通过直播进入小游戏，第二次通过其它非直播场景（如侧边栏、个人主页）进入游戏，则第一次计费，第二次不计费 cpa+cps任务：当天首次通过该直播间进入小游戏的付费用户才计费，该用户后续7日的付费数据均参与计费（包含当日）；如果当天用户在非首次进入直播后付费，仅对cps部分计费和结算。 如果该用户在被直播转化前已被其他短视频/直播绑定（处于7日计费周期内），则不参与当前直播间计费结算 如果该用户历史已被该游戏通过广告投放转化为激活用户，则不参与计费 |
| 总买量费用 | cpa+cps ×预充值任务：包含cps消耗和cpa消耗数据 cpa 或 cpm ×预充值任务：包含cpa 或 cpm消耗数据 cpa 或 cpm × 非预充值任务：包含cpa 或 cpm消耗数据 一口价 × 非预充值任务：包含一口价消耗数据 |
| 消耗进度 | cpa+cps ×预充值任务：分子消耗仅包含cpa消耗数据，分母为预充值冻结金额（用于cpa消耗）。cps消耗将从流量主收入中扣减。  cpa或cpm ×预充值任务：分子消耗包含cpa/cpm消耗数据，分母为预充值冻结金额。  cpa或cpm × 非预充值任务：分子消耗包含cpa/cpm消耗数据，分母为平台固定金额。 |

### 常见问题

---

1、任务转化数据为什么会发生变化？
答：作弊、内容违规、被达人自行删除等类型的投稿视频不计费，因此数据会随着视频的异动进行变化，最终结算费用请以结算单为准。

---

2、将直播任务作为广告素材在巨量投放广告，是否涉及给主播分成？
答：当前投流带来用户转化不参与发行人任务的计费和结算。投放广告带来的用户转化也暂不支持给主播分成，但直播间自然流量转化支持给主播分成（以直播任务配置为准）。

---

3、直播/视频数据指标是否包含广告投流带来的数据？
直播/视频观看次数：包含dou+和广告投流数据
直播/视频观看人数：包含dou+和广告投流数据
买量用户数：不包含广告投流数据，根据任务配置决定是否包含dou+
买量广告收入：不包含广告投流数据，根据任务配置决定是否包含dou+
买量内购收入：不包含广告投流数据，根据任务配置决定是否包含dou+
