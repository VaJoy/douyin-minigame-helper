## 一、什么是 BGDT

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/image-7083871823864787.png)

BGDT（ByteGame Developer Tools），是一个 Unity 游戏开发组件使用与发布的平台。
