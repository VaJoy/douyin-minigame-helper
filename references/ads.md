# 广告变现（流量主）

> **适用**：已开通「流量主」并创建广告位的小游戏。
> **源文档**：`docs/develop/api/javascript-api/ads/`（43 篇）、`docs/develop/guide/open-ability/ad/`（4 篇）。
> **关联**：完整代码片段见 `api-recipes.md` 第 2 节；结算政策见 `ops.md`。

## 先决条件

1. 开发者后台 → **商业化 > 流量主** → 申请开通；
2. **流量主 > 广告管理** → 新建广告位，拿到 `adUnitId`（每种广告形态各建一个）；
3. 广告位状态异常（关闭/封禁）时调用会直接报错，见下方错误码。

## 四种形态怎么选

| 形态 | 创建方法 | 展示位置 | 适合场景 | 最低基础库 |
|---|---|---|---|---|
| 激励视频 | `tt.createRewardedVideoAd` | 全屏 | 复活、双倍奖励、看广告领道具 | 1.3.0 |
| Banner | `tt.createBannerAd` | 指定区域内，原生渲染 | 主页底部常驻 | 1.3.0 |
| 插屏 | `tt.createInterstitialAd` | 全屏，主动调用 | 关卡切换、结算页 | 1.71.0 |
| 游戏推荐组件 | `tt.createGridGamePanel` | 区域内格子 | 推荐其他小游戏，交叉推广 | 2.82.0 |

## 激励视频

```js
const videoAd = tt.createRewardedVideoAd({
  adUnitId: 'xxx',
  multiton: true,                 // 多例模式：可连续看多次拿不同奖励
  multitonRewardMsg: ['奖励1', '奖励2', '奖励3'],
  multitonRewardTimes: 3,         // 多例模式下的可看次数
  progressTip: false,             // 是否显示观看进度提示
});
```

- **必须以 `onClose` 的 `isEnded` 判定是否发奖**，不能只看 `show()` 成功。
- 每用户每天可看次数有平台上限，按钮前先判断 `onLoad` 是否成功过，避免点了没反应。
- 前置条件没满足（未开通流量主 / 广告位无效）时 `show()` 直接 reject。

> 上面只给创建参数。**完整闭环**（预加载、失败重试、发奖判定、销毁）在 `api-recipes.md` 第 2 节，那份是权威版本。

## Banner

- 创建后默认**隐藏**，要显式 `show()`；`onLoad` 触发后再 show 成功率最高。
- 尺寸用 16:9 约定：给定 `width`，高度按 `width / 16 * 9` 估算，`onResize` 会回传真实尺寸。
- 切场景务必 `hide()` 或 `destroy()`，否则会盖在新页面上。
- 反复创建不销毁会累积实例，切换页面时应「销毁旧的、创建新的」。

## 插屏

- 创建后需先 `load()` 再 `show()`；`show()` 返回 Promise。
- 插屏有**频控**：启动后一定时间内、两次广告间隔不足、正在播放其他广告时都会拒绝展示（2001/2002/2003）。
- 实例**不能跨页面调用**（2005），页面切换后应重新创建。

## 常见错误码

| 错误码 | 含义 | 处理 |
|---|---|---|
| 1001 | adUnitId 为空 | 检查创建参数 |
| 1002 | adUnitId 无效 | 后台确认广告位 ID |
| 1003 | 广告组件创建失败 / 宿主不支持 | 降级，不阻塞主流程 |
| 1006 | 当前场景不支持广告 | 换场景或跳过 |
| 1007 | adUnitId 被禁用 | 后台查看违规记录 |
| 1008 | adUnitId 已关闭 | 后台重新启用 |
| 2001 | 刚启动，不允许展示 | 延后展示 |
| 2002 | 距上次广告时间太短 | 做冷却计时 |
| 2005 | 实例跨页面调用 | 重新创建实例 |
| 2006 | 实例已销毁 | 重新创建 |
| 21000 | 各类运行时异常（视频播放中、次数用尽等） | 按 `errMsg` 分别处理 |
| 10301 | 宿主 App 不支持该能力 | `tt.canIUse` 预判 |

## 体验与合规红线

- 不得**诱导点击**（“点广告得奖励”式文案、遮挡关闭按钮、伪装成游戏按钮）。
- 激励视频必须用户主动触发，不能自动弹出。
- 广告展示期间不得静默扣费或推进游戏进度。
- 违规会导致广告位封禁，进而全线报 1007/1008，恢复需走申诉。
- 广告收入结算、分成比例、任务金政策见 `ops.md`，不要在客户端做任何结算逻辑。
