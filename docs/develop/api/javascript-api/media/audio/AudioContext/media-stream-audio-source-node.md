MediaStreamAudioSourceNode 为音频源，该节点的输入源目前只能是来自于麦克风，没有输入，只有一个输出。可以通过[AudioContext.createMediaStreamSource](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/media/audio/AudioContext/audio-context-create-media-stream-source/) 创建。
## 属性
继承其父类 AudioNode 的属性。
## 方法
继承其父类 AudioNode 继承方法。
