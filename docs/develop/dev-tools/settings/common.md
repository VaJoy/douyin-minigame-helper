## 通用设置

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/b2a1580d78f048b18d10dad0275b12fb)

### 语言
当前支持**中文**和**英文**两种语言选择（重启 IDE 后生效）。

### 工作区
用户可设置默认工作区路径。

### 启动项
用户可设置首次启动 IDE 时是否自动打开最后一次的项目。
