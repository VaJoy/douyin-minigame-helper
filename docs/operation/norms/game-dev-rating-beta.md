## 评级体系介绍

**小游戏主体评级体系**，是抖音开放平台为衡量和引导提升小游戏开发者运营水平而制定的评级体系，小游戏开发者获得评级后可获得对应的激励权益。

功能入口：小游戏管理后台-总览-管理-主体评级

![](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/94d1a366afea4f14a66a8248342e7acb~tplv-9nona0m7ha-image.image)

- **评级门槛**

全量在线小游戏开发者主体

> PS：当小游戏开发者产生评级后，平台将自动发放站内信通知，开发者可留意是否接收到相关通知提醒。

- **评级周期**

常规情况：按自然月，每月2日更新评级；

违规情况：当开发者触犯主体封禁违规，将实时降级。

- **评级结果**

小游戏开发者等级一共分为S/A/B/C 4个等级，等级越高说明小游戏开发者经营质量越好，获得平台权益越多

> PS：新入驻小游戏开发者默认为B级

|  |  |
| --- | --- |
| 分级 | 含义 |
| S级 | 经营质量卓越 |
| A级 | 经营质量优异 |
| B级 | 经营质量健康 |
| C级 | 经营质量不佳 |

## 评级体系构成

评级结果由：营收能力、健康经营 2个维度综合得出：

|  |  |  |  |
| --- | --- | --- | --- |
| 模块 | 指标类型 | 指标 | 指标说明 |
| 评分维度 | 营收能力 | 较强营收能力 | 主体月流水≥500万，或主体内容场景月消耗≥30万元 |
| 具备一定营收能力 | 主体月流水≥10万元 |
| 健康经营 | 违规行为 | 近3个自然月是否存在严重违规行为或多次违规行为，  严重违规行为包含不限：反动、赌博、对未成年造成不良影响、色情、黑灰产、线上作弊、重度恐怖元素、侵权、资质造假、运行异常等 |

> ps：若开发者当月2号评级为A级，当月10号开发者出现严重违规行为，则该主体评级等级于处罚落罚T+1下调至C级

## 评级申诉路径

若对主体评级等级变动有异议，开发者可根据个人情况在 7 个自然日内选择申诉。

选择申诉的开发者需要发送邮件到平台邮箱（[mgame@bytedance.com](mailto:mgame@bytedance.com)），根据惩罚类型填写申诉理由并提供相关信息，我们将会在收到有效申诉材料内的 7 个工作日内反馈申诉结果。

若申诉成功，我们则会根据申诉类型进行处理，恢复相应的主体评级等级；失败则维持原判，不作主体评级等级变更。

**申诉流程及规范**

收件人：[mgame@bytedance.com](mailto:mgame@bytedance.com)

邮件标题：【主体评级等级申诉】+开发者主体名称

邮件内容：

1.主体评级页面完整截图：

2.申诉原因：针对异常原因填写申诉理由，并进行相关说明

3.申诉附件：根据申诉原因提供相关图片证明
