## 选择主题
当前支持**深色**和**浅色**两种主题配色。
## 以 Lite 模式打开工程
新建或导入工程时，是否默认使用 Lite 模式启动工作区

## 模拟器布局
当前支持新建工程时，自定义设置模拟器的默认布局（左侧/右侧）。
> 注意：已经存在的工程的布局不受当前配置的影响，只会在创建新的工程时生效。
## 模拟器外壳
当前支持切换模拟器的设备外壳的显示与隐藏。
