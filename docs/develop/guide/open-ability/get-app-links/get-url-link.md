该接口用于生成能够直接跳转到端内小游戏的 url link。

### 调用上限
该接口设定有频次控制，每个小游戏，100qps，50w次/自然日。如有特殊需求联系oncall。
详见[生成Link](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/server/link/generate-link)
