> **源文档**：`docs/operation/`（101 篇：用户运营 31 / 数据分析 24 / 平台能力 3 / 运营规范 20 / 服务协议 23）。

## 游戏管理工作台

后台「游戏管理」是所有运营动作的入口：

| 模块 | 能做什么 |
|---|---|
| 游戏概览 | 昨日分成收入、昨日活跃用户。**每天 14:00 前**更新前一日数据，只统计当前工作台下的游戏 |
| 热点速递 | 平台热点趋势，指导选题与活动 |
| 游戏列表 | 已上线 / 待上线 / 已下架三态；可看版本审核进展、收入与用户数据、已接入能力 |
| 通用配置 | 域名、调试设备一次配置，工作台下所有游戏生效 |
| 权限配置 | 超管可添加协作成员，但**游戏详情页权限仍需单独在「账号中心-协作成员」添加** |

工作台按「主体 + 超管」划分，不同主体下的游戏要切换工作台查看，数据不互通。

## 数据分析

四类看板：

| 看板 | 子项 | 用途 |
|---|---|---|
| 用户分析 | 行为、实时、留存、来源、画像、终端 | 看 DAU/新增/时长/留存曲线 |
| 性能分析 | 启动数据、错误监控、运行性能、网络性能 | 定位卡顿、崩溃、加载慢 |
| 增长分析 | 分渠道新增激活与后效 | 评估买量与内容投放 ROI |
| 自定义分析 | 事件管理、事件分析、漏斗、火山引擎增长分析 | 自定义埋点做转化漏斗 |

指标口径要注意：
- 「活跃用户」按 uid 去重，与工作台列表口径一致；
- 「人均游戏时长」= 总时长 / 去重活跃人数；
- 收入类指标分为「分成前」与「分成后」，别混用。

## 用户留存

| 手段 | 关键点 |
|---|---|
| **侧边栏复访**（必接） | 所有游戏必须接，直接影响推荐权重 |
| 订阅消息 | 用户授权后推送体力恢复、活动开启 |
| 排行榜 | IM 原生榜或自绘榜，见 `social.md` |
| 群聊 / 粉丝群 | `tt.joinGroup` 入群，满员要能切二群 |
| 关注抖音号 | 关注组件 + 内容更新提醒 |
| 版本更新提醒 | 新版本可用时提示用户 |

## 商业化

### 广告（IAA）

接入见 `ads.md`。运营侧关注：广告位配置、eCPM 波动、激励视频人均次数。

### 内购（IAP）

接入见 `payment.md`。运营侧关注：支付转化率、ARPPU、退款率。

### 金币激励（抖音极速版）

- 面向**抖音极速版**（宿主 appid=2329），发的是极速版金币，用户可提现。
- **准入制**：需满足平台数据标准后填问卷报名，不是所有游戏都能开。
- 投放位置：极速版任务页有稳定复访入口，按前 7 日场景来量流水排名，**单日取前 32 名**给曝光。
- 接入注意：版本提交时必须勾选「抖音极速版」；发放点位命名用「游戏名+自定义点位名」；素材必须用官方统一素材；游戏内要按模板嵌入活动规则。

## 结算与对账

- 结算政策、分成比例、任务金/投放金激励规则都在 `docs/operation/agreement-and-norms/` 与结算政策页。
- 支持 T+1 提现（需单独开通）。
- 对账以服务端流水为准，客户端不做任何金额计算。
- 小规模纳税人税率有专门政策说明，开票前先看当年公告。
