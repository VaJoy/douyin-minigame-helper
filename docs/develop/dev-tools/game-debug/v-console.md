## 简介
调试控制台（vConsole）用于帮助开发者解决和排线上异常问题，开发者可以在客户端打开“开发者模式”后，找到调试控制台（vConsole）的开关。

## 版本要求
抖音版本要求：>= 27.1.0。

## 使用方法
### 加入小游戏的测试账号列表
1. 参考：[真机调试-获取调试权限。](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/dev-tools/game-debug/real-machine-adjust)
1. 加入测试设备后，在抖音客户端中点击【我】- 右上角【更多】，在“更多功能”或者页面底部找到 【开发者模式】并点击，进入开发者模式页面。首次加入测试账号时会自动引导跳转到该页面。

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/f21c071201fc43828b091218c72692e4)

### 启用“调试控制台”
首先开启“开发者模式”（Android 版需要重启才能生效），进入要调试的小游戏子菜单，打开“调试控制台”。

![screenshot](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/d87af83e77a3440fa52049ddc537c61e~tplv-9nona0m7ha-image.image)

### 使用调试控制台
“调试控制台”可以在客户端真机上展示 vConsole，方便开发者查看线上版小游戏打印在 console 中的各种变量，以排查线上问题。

若需要查看控制台 Console 日志，打开小游戏后，在右上角点击【...】，点击【打开调试】，点击 vConsole，即可查看相关日志。
