#### 直播场景内容建议

|  |  |
| --- | --- |
| **※针对近期iAA游戏直播场景数据波动，主要波动的内容在游戏【副玩法】板块，关于副玩法的设计，以下是运营视角的洞察和建议：** | |
| **问题** | **建议** |
| 1.**玩法路径较深**  a.玩半个小时（或者玩1-2关）才能解锁副玩法  b.游戏主页没有明显副玩法的指引路径 | 1.**副玩法设置入口更容易找到**：游戏主页面设置副玩法解锁指引路径，让从直播间副玩法进入游戏的用户更快找到直播间同玩法，厂商同样可引导主播在播副玩法的时候将副玩法的路径在直播间更清晰的展示  2.**副玩法更容易被解锁**：将解锁门槛放低，新进入游戏的用户在未体验游戏的情况下，可能耐心不够，如解锁门槛过高，可能会产生对于直播间的负反馈，导致直播间流量受影响 |
| 2.**游戏副玩法趋同**  a.直接移植平台较火的副玩法  b.副玩法内容低质 | 1.**副玩法应有更多原创 内容**：学习借鉴平台上较火的副玩法的模式，在学习的基础上**创意升级是必要的**，趋同的玩法易造成直播间的观众和用户审美疲劳，久而久之直播间流量下降，会直接影响开播量，对于直播场景会有较大影响 |
| 3.**副玩法和主玩法差异太大**  a.副玩法跟主玩法完全不是同一品类的游戏，会引起用户负反馈 | 1.**副玩法应贴合游戏本身的玩法和画风**：从播着副玩法的直播间进入游戏的用户，大部分是对于副玩法感兴趣，进入游戏后发现游戏内的画风和玩法差异过大，会造成对直播间的负反馈，认为是**【货不对板】**负反馈会对直播就间的推荐有影响，导致直播间流量下降，同样对直播场景的收入有影响 |
