通过[tt.createBannerAd](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/ads/tt-create-banner-ad)创建的广告实例。
## 属性说明
| 属性名 | 类型 | 说明 |
| --------- | -------- | ---------------------------- |
| show | Function | 展现广告 |
| hide | Function | 隐藏广告 |
| onLoad | Function | 绑定 load 事件的监听器 |
| offLoad | Function | 解除绑定 load 事件的监听器 |
| onError | Function | 绑定 error 事件的监听器 |
| offError | Function | 解除绑定 error 事件的监听器 |
| onResize | Function | 绑定 resize 事件的监听器 |
| offResize | Function | 解除绑定 resize 事件的监听器 |
| destroy | Function | 销毁广告实例 |
