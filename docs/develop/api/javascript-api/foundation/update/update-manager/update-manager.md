小程序版本更新管理器对象，[tt.getUpdateManager](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/update/tt-get-update-manager)方法返回值。
## 属性说明
| 属性名 | 类型 | 说明 |
| ---------------- | -------- | ---------------------- |
| onCheckForUpdate | function | 版本信息请求完成的回调 |
| onUpdateReady | function | 新版本下载成功的回调 |
| onUpdateFailed | function | 新版本下载失败的回调 |
| applyUpdate | function | 应用新版本 |
