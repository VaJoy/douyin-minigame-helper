> **适用**：游戏礼包/兑换码、手势识别、URL Link 与添加到桌面。
> **源文档**：`docs/develop/guide/open-ability/gift-bag/`（5 篇）、`ai/`（1 篇）、`get-app-links/`（2 篇）。
> **关联**：分享与邀请见 `social.md`；礼包的商业化政策见 `ops.md`。

## 一、游戏礼包

### 三种形态

| 形态 | 场景 | 特点 |
|---|---|---|
| 直播福袋礼包 | 主播在直播间发福袋 | 中奖后带 `cdkey` 进游戏 |
| 限时付费礼包 | 游戏内向用户推荐折扣礼包 | 需宿主 32.4.0+，有频控 |
| 游戏站登录/签到礼包 | 小游戏站内签到领取 | 承接游戏站流量 |

### 核心概念

- **道具**：礼包兑换的游戏内虚拟资源，配置礼包前要先把道具建好（名称、图标、道具 ID）。
- **礼包码（cdkey）**：平台按库存数量自动生成的随机串，在同一个 appID 内唯一，**一人一码**。
- **库存**：分「无库存限制」和「有库存限制」；有库存时每发一个码库存 -1，领完即止。

### 兑奖流程

```
用户在直播间中奖 → 跳转/手动进游戏
        ↓
游戏内 tt.onShow 的 query 里带 game_cdkey
        ↓
把 cdkey 发给自己的服务端 → 调平台「兑奖 OpenAPI」
        ↓
平台核销（一人一码）→ 服务端发货 → 客户端提示
```

```js
tt.onShow((res) => {
  const cdkey = res.query && res.query.game_cdkey;
  if (!cdkey) return;                       // 手动复制码进来的用户不会有这个字段
  tt.request({
    url: 'https://your-server/api/redeem',
    method: 'POST',
    data: { cdkey },
    success(r) { toast(r.data.ok ? '兑换成功' : '该码不可用'); },
  });
});
```

几个容易踩的点：

- **不是所有路径都带 cdkey**：从直播间中奖页跳转、站内信链接跳转会自动带；用户手动复制码进来不会带，所以要另外做一个手动输入入口（后台配置的「领取路径」就是干这个的）。
- **别自己校验 cdkey**：平台生成的是随机串，除了调兑奖 OpenAPI 之外不需要也不应该做额外校验。
- **生效期 vs 领取有效期是两回事**：生效期控制礼包什么时候能发，领取有效期控制用户中奖后多久内必须兑，过期作废。
- 兑奖必须服务端做，客户端只负责把码传上去。

### 限时付费礼包

| 项 | 要求 |
|---|---|
| 宿主版本 | 抖音 / 抖音极速版 **32.4.0+**，其他宿主待定 |
| 屏幕方向 | 暂仅支持**竖屏** |
| 定价 | 现价 ≤ 原价，可自由定价 |
| 库存 | 单次配置上限 50,000，库存为 0 后不再推荐 |
| 频控 | 命中逻辑的用户 1 天最多收到 1 个付费礼包推荐 |
| 推荐优先级 | 已购买 < 已推荐 < 未推荐 |

礼包名称要有唯一性，生效时长建议 3 个月以上。

## 二、AI 手势识别

平台内置手势识别，不需要自己接算法：

```js
const detector = tt.createHandDetector();   // 基础库 1.66.0+
const result = detector.detect();           // 返回 HandInfo
```

- 可识别的静态手势包括比心（双手/单手多种形态）、点赞/点踩（拇指朝上/朝下）、OK、拳头、手掌等，每种都有明确的角度与遮挡条件（官方文档给了图示）。
- 适合做「手势触发特效/彩蛋」这类玩法，不适合做精确输入。
- 同目录还有 `tt.createFaceDetector`（1.37.0+）做人脸检测。
- 官方标注这两个接口**无需开发者授权、无需用户授权**（`createHandDetector` / `createFaceDetector`）；只有你自己去采集摄像头画面时才涉及 `scope.camera`。

## 三、外部入口

### 添加到桌面（默认支持）

用户从右上角胶囊 → 详情页 → 「添加到桌面」即可，**开发者不接也能用**。原生 API：

| API | 作用 | 版本 | 平台 |
|---|---|---|---|
| `tt.addShortcut` | 主动添加桌面快捷方式 | 2.46.0 | iOS / Android |
| `tt.checkShortcut` | 检查是否已添加 | 2.46.0 | **仅 Android** |

坑：

- **只有正式版支持**，开发版/体验版加不了，需要用开发者工具的自定义编译条件测。
- 从桌面打开时 `scene` 值按宿主不同：抖音 `021020`、极速版 `101020`、今日头条 `011020`、番茄小说 `181020`、手机桌面 `991020`。做渠道归因时要把这些值都覆盖到。

### URL Link

用于在端外（短信、网页、广告落地页）拉起小游戏：

- **服务端生成**，调平台「生成 Link」接口，客户端没有对应 API。
- 配额：单小游戏 **100 QPS、50 万次/自然日**，超了要联系 oncall。
- 配额查询有单独接口。

和分享的区别：分享走客户端 `tt.shareAppMessage` 生成分享卡片；URL Link 是服务端按需生成的可投放链接，适合买量和站外引流。
