## 语法

```js
cancelAnimationFrame(requestId)
```
基础库 1.0.0 开始支持本方法，这是一个**同步**方法。
取消一个先前通过调用 requestAnimationFrame 方法添加到计划中的动画帧请求。

## 参数
| 属性名 | 类型 | 必填 | 默认值 | 最低版本 | 说明 |
| --- | --- | --- | --- | --- | --- |
| requestId | number | 是 |  | 1.0.0 | 调用 requestAnimationFrame 方法添加到计划中的动画帧请求的 Id |

## 授权要求
无需开发者授权；无需用户授权

## 支持平台
iOS、Android
