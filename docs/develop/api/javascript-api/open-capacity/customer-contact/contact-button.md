---

## 属性
无
## 方法
  
| 方法名 | 说明 | 最低支持版本 |
| --- | --- | --- |
| destroy() | 销毁按钮。 | 1.55.0 |
| show() | 显示按钮。 | 1.55.0 |
| hide() | 隐藏按钮。 | 1.55.0 |
| onTap(function callback) | 监听按钮点击事件。 | 1.55.0 |
| offTap(function callback) | 移除 onTap 绑定的监听函数。 | 1.55.0 |
| onError(function callback) | 监听创建客服按钮出现的错误。 | 1.55.0 |
| offError(function callback) | 移除 onError 绑定的监听函数。 | 1.55.0 |
