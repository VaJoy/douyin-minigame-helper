抖音小游戏面向多宿主提供了方便接入的 SDK，目前已在多个 App 中集成小程序/小游戏平台，但不同的宿主运行环境和更新频率无法保持完全一致，所以在能力支持上存在部分差异，本文主要介绍各个 App 的使用限制。
## 支持宿主

| 宿主名称 | 支持情况 | 说明 |
| --- | --- | --- |
| `抖音` | `双端` | 目前能力支持最全的宿主，第一时间同步平台最新能力。 |
| `抖音极速版` | `双端` | 暂无 |
| `今日头条` | `双端` | 暂无 |
| `今日头条极速版` | `双端` | 暂无 |
| `抖音火山版` | `双端` | 暂无 |
| `番茄畅听` | `双端` | 暂无 |
| `番茄小说` | `双端` | 暂无 |
| `红果短剧` | `双端` | 暂无 |

## 游客访问

> **注意**
> 小游戏目前不支持游客访问，所有用户进入小游戏需实名认证，会要求必须登录（这里的强制登录开发者不需要关心）。
