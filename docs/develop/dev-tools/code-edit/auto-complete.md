同大部分编辑器一样，工具提供了较为完善的自动补全。
- js/ts 文件编辑会帮助开发者补全所有的 API 及相关的注释解释，并提供代码模板支持。
- json 文件编辑会帮助开发者补全相关的配置，并给出实时的提示。

## JS 补全
JS 补全：JS 文件编辑会帮助开发者补全所有的 API 及相关的注释解释，并提供代码模板支持。

JSON 补全：JSON 文件编辑会帮助开发者补全相关的配置，并给出实时的提示。
