| 名词 | 简称/其他称呼 | 解释 | 备注 |
| --- | --- | --- | --- |
| Native方案 | Native、原生方案 | 抖音Unity小游戏的一种开发方案，完全适配游戏引擎的原生性能和特性[SC使用方案及引擎选择建议](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/sc_engine_selection_suggestion)。 |  |
| WebGL方案 | wasm方案 | 将游戏产物导出成可以在浏览器环境运行的一种方案。 在抖音Unity小游戏中游戏代码会被导出为wasm代码，并通过胶水层代码运行在浏览器环境。 |  |
| 小包化 |  | 通常指将游戏的首包大小缩减的工作，由于即玩游戏对下载时长有严格要求，所以开发者需要缩减游戏首包大小来降低加载时长。 |  |
| C# SDK | Unity SDK | 抖音Unity小游戏提供的一套C# SDK用于为开发者提供各种宿主的开放能力，包含登录、广告、分享等能力。[C# SDK文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/sc_stark_sdk) |  |
