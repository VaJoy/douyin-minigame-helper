性能监控中提供了流畅度、内存、处理器 三类性能指标。

### 一、流畅度

展示了所选时间范围内的FPS、卡顿率、渲染指标（Drawcall、三角形函数、顶点数）、FPS分布。

![](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/97e0a806d98a424c947210670dcd6e55~tplv-9nona0m7ha-image.image)

### 二、内存

展示所选时间范围内的内存均值、内存占用率、Unity Heap内存峰值（仅unity webgl方案有数据）、内存崩溃率（仅IOS下高性能或高性能+模式有数据）、内存崩溃明细数据（仅IOS下高性能或高性能+模式有数据）。

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0afa7d8d57d04a4e88c387010dbcff19~tplv-goo7wpa0wc-quality:q75.image)

### 三、CPU

展示所选时间范围内的CPU占用率、GPU占用率。

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e5afc9f53a494abb9e1ea42aea292f37~tplv-goo7wpa0wc-quality:q75.image)
