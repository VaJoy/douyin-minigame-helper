## 一、账号找回
- 当前仅支持「超级管理员」通过主体认证方式找回账号，暂不支持其他类型账号找回。
- 以下流程支持[抖音开放平台](https://developer.open-douyin.com/login?service=https%3A%2F%2Fdeveloper.open-douyin.com%2Fapply%2Fmodify)账号找回。
**操作流程**

| **操作步骤** | **相关页面** | **流程说明** |
| --- | --- | --- |
| 步骤1：找到入口 |  | [抖音开放平台](https://developer.open-douyin.com/login?service=https%3A%2F%2Fdeveloper.open-douyin.com%2Fapply%2Fmodify)——登录遇到问题——立即找回 |
| 步骤2：提交找回申请 |  | 根据页面提示，录入准确的资质信息进行超管账号找回  特别注意：用于接收"账号找回处理单号"的同一个手机号每天最多可提交5次 |
| 步骤3：验证资质信息 | 法定代表人/经营者支付宝人脸识别验证   银行账户实名认证   客户向平台打款验证 | 支持3种方式对公验证，用户可依据自身情况和时效选择对应方式：  法定代表人/经营者支付宝人脸识别验证（实时完成）  银行账户实名认证（实时完成）  客户向平台打款验证（需要48小时内完成）  具体规则详见：[注册与入驻](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/register) |
| 步骤4：返回验证结果 | 法人人脸识别/银行账户四要素验证   客户向平台打款验证 | 如果选择法人人脸识别/银行账户四要素验证，则实时展示结果  如果选择的是商户向平台打款，会在1-2个工作日验证成功后展示结果    短信通知：  抖音开放平台：【抖音开放平台】您的账号找回申请单号为xxxx，可前往「抖音开放平台-登录-登录遇到问题-查询找回进度」使用申请单号加手机号组合查询账号找回结果。 |
| 步骤5：查询找回进度 | 成功    失败 | 需要使用手机号和申请单号组合查询，手机号需要短验  找回失败需根据验证失败提示修改验证信息重新验证 |

## 二、账号换绑
账号已登录时，开发者可在[【账号中心】](https://developer.open-douyin.com/info)-【账号管理】-【基本信息】处，点击【修改】换绑手机号/邮箱号。
换绑时需要原绑定手机号/邮箱接收验证码，如原手机号/邮箱号无法接收验证码或因此导致无法登录账号，可参考下方【账号申诉流程】，通过账号申诉的方式进行换绑。

![screenshot](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/6b980df28bf043f09247fbf19e31f41b)

### 账号申诉流程
账号申诉流程适用于原手机号/邮箱无法接收验证码或企业主体更换运营人员时，更换绑定的手机号/邮箱。
需同时满足如下三个条件才可操作账号换绑：
1. 仅支持超级管理员账号申诉；
1. 超管账号已成功入驻[抖音开放平台](https://developer.open-douyin.com/)且未转移/未发起注销的账号申诉。
1. 仅支持企业主体账号申诉；
*如不满足上述条件,请通过开发者平台-右下角「开发者助手」-「在线客服」-描述问题或输入两次「人工客服」-进入「在线人工客服」-选择【小游戏-非技术问题】进行咨询
*如遗忘原绑定手机号/邮箱，可参考【账号找回流程】，找回账号后再进行申诉。
**操作流程 **

| **操作步骤** | **相关页面** | **流程说明** |
| --- | --- | --- |
| 第一步：找到入口 |  | [抖音开放平台](https://developer.open-douyin.com/)——登录遇到问题——账号申诉——立即申诉 |
| 第二步：填写换绑信息申请申诉 |  | 根据页面信息所需信息进行填写  **申诉账号：** 如是手机号换绑填写目前**已被绑定的手机号**即可  如是邮箱换绑填写目前**已被绑定的邮箱**即可  注意：入驻成功后且未发起注销/转移的账号才可以进行换绑  **申诉原因：**必填，且最少输入10字 **企业认证主体名称：**账号已认证的主体名称  **主体信用代码：**账号已认证主体的统一信用代码  **法人姓名：**与账号已认证主体的证照法人信息一致  **主体类型：**与已认证的主体类型保持一致  **填写手机号：**根据实际情况换绑未注册过[抖音开放平台](https://developer.open-douyin.com/)账号的手机号或邮箱，申诉成功后平台将当前账号自动绑定到该手机号/邮箱，确保换绑的手机号/邮箱可正常接收验证码信息  注意：系统自动检验手机号/邮箱已被绑定过其他的账号，**如果被绑定则直接报错提示：该手机号/邮箱已被绑定到其他账号，请更换** |
| 第三步：验证信息 |  | 支持3种方式对公验证，用户可依据自身情况和时效选择对应方式：  法定代表人/经营者支付宝人脸识别验证（实时完成）  银行账户实名认证（实时完成）  客户向平台打款验证（需要48小时内完成）  具体规则详见：[注册与入驻](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/register) |
| 第四步：返回结果信息 |  | 如果选择法人人脸识别/银行账户四要素验证，则实时展示结果  如果选择的是客户向平台打款，会在1-2个工作日验证成功后展示结果  通知信息：  邮件通知：账号申诉处理单号为xxxx，可前往「抖音开放平台-登录-登录遇到问题-查询申诉进度」使用处理单号加当前手机号/邮箱组合查询账号申诉结果。  短信通知：【抖音开放平台】xxx的账号申诉处理单号为xxxx，可前往「抖音开放平台-登录-登录遇到问题-查询申诉进度」使用处理单号加当前手机号/邮箱组合查询账号申诉结果。 |
| 第五步：查询换绑进度 | 验证中   申诉成功   申诉失败 | 验证中：如果是对公打款进行中，则展示详细的打款信息，根据提示等待/继续完成验证即可  申诉成功：  邮件通知：账号xxx申诉成功！已绑定当前手机号/邮箱，请前往抖音开放平台进行登录。  短信通知：【抖音开放平台】账号xxx申诉成功！已绑定当前手机号/邮箱，请前往抖音开放平台进行登录。  申诉失败：根据验证失败提示修改验证信息重新验证  邮件通知：由于xxxxxxx已被其他账号绑定，账号xxx申诉换绑失败！可以前往「抖音开放平台-登录-登录遇到问题-立即申诉」重新发起申诉，请提交未被注册的手机号或邮箱进行换绑。  短信通知：【抖音开放平台】由于xxxxxxx已被其他账号绑定，账号xxx申诉换绑失败！可以前往「抖音开放平台-登录-登录遇到问题-立即申诉」重新发起申诉，请提交未被注册的手机号或邮箱进行换绑。 |
