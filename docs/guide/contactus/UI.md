## 一、按钮的交互
### 1.按钮点击无反应或提示错误文案
**审核规范：**小游戏按钮点击无反应或出现错误文案，不符合平台要求。
**常见拒绝场景：**

| ❌视觉上可交互的按钮点击无反应或提示错误文案，未实现其功能 |
| --- |
|  |

**修改指引：**游戏视觉上可交互的各功能按钮均可正常点击，点击需实现对应功能，功能未开放时点击需有友好提示文案。
### 2.按钮重叠
**审核规范：**按钮与框架按钮重叠，不符合平台要求。
**常见拒绝场景：**

| ❌游戏内的功能按钮与框架按钮重叠，或按钮之间相互重叠，或按钮与重要文案重叠，影响用户操作或易导致误触，或影响观感 | |
| --- | --- |
|  |  |

### 3.按钮生效区域未覆盖
**审核规范：**按钮生效区域未覆盖整个按钮，不符合平台要求。
**常见拒绝场景：**

| ❌生效区域＞按钮范围，点击空白处掉起视频广告 | ❌生效区域＜按钮范围，生效区域未完整覆盖 |
| --- | --- |
|  |  |

**修改指引：**按钮设置的区域点击需有正确反馈，按钮覆盖范围有多大，点击生效的区域应正常实现，不可点击无反应或超出范围导致误触，影响用户体验。
### 4.非平台功能描述及按钮
**审核规范：**小游戏存在非本 APP 功能文案，不符合平台要求。
**常见拒绝场景：**

| ❌在某一宿主内文案只允许出现该APP的相关功能。  游戏内禁止出现其他宿主端引导文案和功能（左图），不能带有非平台的功能描述及按钮（右图） | |
| --- | --- |
| 该场景为头条端出现关注抖音功能 | 该场景为出现其他平台功能 |

**修改指引：**

- 游戏内若存在相应端口的引导需进行适配，如在头条端"一键关注抖音号"无法实现不可接受，若有相应引导可接受，如点击提示“请前往抖音端进行关注”等。
- 游戏内部元素或展示图案不可出现非本平台的产品或功能描述，如其他产品的logo或功能提示等。

## 二、按钮显示文案
### 1.测试类数据
**审核规范：**小游戏存在"测试"类数据，不符合平台要求。
**常见拒绝场景：**

| ❌常见不规范“测试”类数据展示为：NAN（左图）、undefined（右图）、null、测试测试、test、以及游戏后台代码等 | |
| --- | --- |
|  |  |

**修改指引：**游戏内不可存在后台开发者模式更改游戏数据；可允许存在内测板块或内测员模式。
### 2.英文或复杂英文
**审核规范：**游戏中不可出现复杂英文和其他语言。
**常见拒绝场景：**

| ❌出现复杂英文 | ❌出现未知语言 |
| --- | --- |
|  |  |

**修改指引：**简单的英语展示没问题，但是出现太复杂的英文或其他语言高频，会对用户造成一定困扰。
### 3.平台支持功能提示错误文案
**审核规范：**小游戏存在非本端功能文案，不符合平台要求。
**常见拒绝场景：**

| ❌平台支持的功能，如“分享、广告视频”等，用户点击却显示无法实现且提示错误文案 |
| --- |
|  |

**修改指引：**上线平台端口的游戏功能均需有对应的实现，允许功能模式暂未开放，但不可出现设置对应板块点击却提示”平台不支持“的情况。
### 4.素材出现水印
**审核规范：**游戏素材存在水印，不符合平台要求。
**常见拒绝场景：**

| ❌图片素材存在水印 |
| --- |
|  |

**修改指引：**引用的背景图片或游戏内设置的头像素材等建议去除图片的水印（包括不限于用户昵称、第三方平台 app 等），避免引起隐私泄露或侵权的风险。
### 5.与其他产品 icon 接近的素材
**审核规范：**游戏存在与其他产品 icon 接近的素材，不符合平台要求。
**常见拒绝场景：**

| ❌直接使用其他社交产品icon，会混淆用户的感知 | ❌直接使用其他产品的logo存在商标侵权风险 |
| --- | --- |
|  |  |

**修改指引：**建议游戏内部的交互按钮及素材不要使用第三方平台的标识，允许适当出现剧情需要的相关 app 文案。
## 三、第三方引流
**审核规范：**小游戏不可出现第三方引流，如需添加客服功能请参考文档接入。
### 1.第三方引流方式
**能力展示：**

| 平台抖音号、官方QQ、官方邮箱、官方群组等  认证了官方的联系方式可接受 | | 平台规范客服设置，可接受 | 允许在小6客服里  出现qq、群、微信、邮箱等联系方式 |
| --- | --- | --- | --- |
|  |  |  |  |

**常见拒绝场景 1：**

| ❌微信公众号等非企业联系方式或官方群组不可接受，恶意引流 |
| --- |
|  |

**常见拒绝场景 2：**

| ❌不可使用二维码（左图）或有完整编号条形码（右图）进行引流错误案例 | |
| --- | --- |
|  |  |

**常见拒绝场景 3：**

| ❌不可在游戏内设置真实且可拨通的个人联系方式 |
| --- |
|  |

**常见拒绝场景 4：**

| ❌客服展示为邮箱 | ❌客服展示为QQ | ❌小6客服里，出现URL链接 |
| --- | --- | --- |
|  |  |  |

**修改指引：**

- 建议提供用户交流群、Q群、企业版微信、邮箱等官方为用户提供服务的渠道，不可出现公众号、非官方客服等直接引流方式。
- 手机号允许出现错误、空号或进行**打码的情况；企业联系方式或游戏剧情需要可接受。

1. 恶意引导或唤起下载

**常见拒绝场景 1：**

| ❌禁止公告上引导添加第三方平台的客服购买道具，用户权益无法得到保障 |
| --- |
|  |

**常见拒绝场景 2：**

| ❌禁止让用户下载app（左图），或绑定第三方平台小程序（右图）获得奖励 | |
| --- | --- |
|  |  |

**常见拒绝场景 3：**

| **❌**主动弹出链接，提示跳转去浏览器下载 |
| --- |
|  |

**常见拒绝场景 4：**

| ❌禁止引导用户报名或参加线下活动 |
| --- |
|  |

**常见拒绝场景 5：**

| ❌禁止唤起任何下载 |
| --- |
|  |

**修改指引：**

- 建议开发者运营活动时，设置平台规范的小6客服，由客服引导用户进行规范的操作。
- 链接允许出现单纯官网网址介绍，但点击不跳会转的场景。

### 2.绑定手机号
**常见拒绝场景：**

| ❌禁止出现绑定邮箱、手机号等可以用作其它渠道或者端口登陆的账号信息和凭证 | |
| --- | --- |
|  |  |

**修改指引：**不可强制用户填写，可设置选填等选择。
