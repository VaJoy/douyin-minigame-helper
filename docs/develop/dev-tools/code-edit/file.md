## 编辑区基础操作
开发者可以在编辑区内对当前项目进行以下操作：
- 代码编写与修改
- 文件添加/删除
- 文件重命名
- 目录结构调整

## 文件编码规范
由于iOS仅支持**UTF-8** 编码格式，项目代码文件必须使用 **UTF-8** 编码格式。开发者工具会在代码上传时自动进行编码格式校验。

## 支持的文件类型
编辑器支持以下文件类型的编辑和操作：
1. 脚本文件：`.js`
1. 配置文件：`.json`
1. 游戏资源文件：`.png`, `.jpg` 等图片格式（支持预览）
1. 样式文件：`.css`
1. 模板文件：`.ttml`

## 自动保存
启用`设置 > 编辑器 > 文件保存>自动保存`后，工具会自动帮助用户保存当前的代码编辑状态

![screenshot](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/db222c1a001948ba8dc50d58ff815f7f~tplv-9nona0m7ha-image.image)

## 实时预览功能
启用了`详情>工程配置>修改文件的时候自动编译`后，当文件修改时，可以通过模拟器实时预览编辑的情况
