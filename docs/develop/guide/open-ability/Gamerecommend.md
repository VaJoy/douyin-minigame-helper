`该能力预计24.2版本上线，安卓2月14号左右支持可用`
> 本文档主要介绍平台开放的“游戏推荐组件”，预计能够为您的游戏带来流量的提升
### 用户追求更丰富的游戏体验
随着小游戏行业的不断发展，游戏品类越来越丰富，用户不再拘泥于单一品类的游戏体验，而是不断尝试更多不同类型的游戏，用户的人均游戏款数也在逐日提升，同时我们也发现，在抖音小游戏中心中，我们将平台的游戏做了聚合展示，分品类分专题向用户推荐游戏，人均点击的游戏款数也大于 3 款以上
因此，我们很容易发现一个结论：**用户在追求更丰富的游戏体验，并勇于尝试不同的游戏品类**
### 为用户畅玩更多游戏提供清晰的产品路径
除了用户本身心智外，作为游戏产品，需要给到用户清晰的产品路径，让用户更快速准确地畅玩更多游戏，平台经过实验判断，最合适的推荐场景是在游戏内，这条路径明显会有更多的优势
> 游戏内直接可以跳转到其他游戏，路径简洁
>
> 开发者可以根据自己的游戏品类去提前判断用户的兴趣偏好，给到更精准的游戏推荐
>
> 游戏内容有限或用户感到乏味时，其他的游戏推荐能够为用户带来更新鲜的刺激，延长用户的使用时长
针对以上有限，平台提供了“游戏推荐组件”的 API 能力，接入后，可以在游戏内快捷拉起游戏推荐面板，让用户能够在游戏内直接打开另一款小游戏
![](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/image (8)-3583586330573931.5.png)
### 为开发者带来更多私域运营空间
#### 主动调用展示
在使用这个组件之前，作为游戏开发者，可以在后台配置你需要展示的游戏，你所配置的游戏会在组件中置顶，若配置不足，则平台会自动为您填充满游戏，无需担心
因此，若一家游戏工作室同时有多款游戏，便可以快速通过这个组件，构建起不同游戏之间的流量通路，用户在 A 游戏获得了良好的游戏体验之后，可以前往 B 游戏进行游戏体验，在工作室的视角下，这个用户能够给工作室旗下的游戏贡献了更多的时长
#### 广告填充兜底
此外，除了主动调用游戏推荐组件作展示之外，平台也会在您的游戏出现 「banner 广告/插屏广告」 填充不足的情况下，用游戏推荐组件做替代展示，在完成了游戏配置的前提下，你所希望展示的游戏都能够获得持续有效的曝光，获得更多流量
### **及时有效的数据反馈**
推荐组件也提供了用户行为监听的数据，您可以清楚知道用户点击了哪个游戏，方便您判断组件的曝光效果并调整您的策略或排序
### 具体使用方法
**Step1：在小游戏开发者平台配置游戏**

1. 在小游戏开平进入【游戏 A】的【运营-运营能力-互推资源位】中进行配置
2. 被配置的【游戏 b】、【游戏 c】、【游戏 d】等，都必须是和【游戏 A】**同主体、且在抖音上线了的游戏**
3. 配置款数不足时（如九宫格只配置了4款），剩余的空格将会展示平台推荐的兜底游戏；

![](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/image (9)-5456359335421688.png)
**Step2：**点击文档 [游戏推荐组件](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/grid-game-panel/tt-create-grid-game-panel)，根据接口文档进行接入，您可以自定义以下内容**

- 格子展示的时机
- 格子的样式（单宫格、四宫格、九宫格）
- 格子的大小（提供百分比缩放）
- 用户的行为（可以监听用户点击动作，或在用户启动其他游戏时埋入的 query 参数，在其他游戏启动时做监听，实现用户启动的来源判断）

### 最佳实践

- 游戏内制作悬赏任务，引导用户进行试玩，通过监听用户点击行为进行发奖
- 通过在游戏内绘制「更多游戏」按钮，用户点击后拉起游戏推荐面板
- 在「关卡中间 & 暂停页」等，展示四宫格
