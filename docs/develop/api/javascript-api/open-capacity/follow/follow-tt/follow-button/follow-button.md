> 基础库 1.19.0 开始支持本方法，低版本需做[兼容处理](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/basic-library/compatibility-description/)。 暂时只支持在今日头条 App 上使用。
关注按钮实例，可通过 [tt.createFollowButton](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/tt-create-follow-button) 获取。通过它能够监听关注按钮的相关操作。
## 方法
### [FollowButton.onTap](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/follow-button/on-tap)
监听按钮点击事件。
### [FollowButton.offTap](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/follow-button/off-tap)
移除指定的按钮点击监听事件。
### [FollowButton.destroy](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/follow-button/destroy)
销毁关注按钮。
### [FollowButton.show](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/follow-button/show)
显示关注按钮。
### [FollowButton.hide](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/follow/follow-tt/follow-button/hide)
隐藏关注按钮。
