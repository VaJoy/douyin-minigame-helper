开发者可以通过以下两种方式进行版本管理。

## 初始化仓库
### 方式一：可视化界面
点击源代码管理图标，初始化仓库

![screenshot](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/ccf6fe51ae3649f8b4d96feec31727d0~tplv-9nona0m7ha-image.image)

### 方式二：git命令
终端输入`git init`初始化项目

![screenshot](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/8705902b831d49dcb0d44bac24bc5995~tplv-9nona0m7ha-image.image)

## 提交工作区更改
可以通过`git commit`命令进行提交，也可以通过以下界面提交

![screenshot](https://p9-douyin-open.byteimg.com/tos-cn-i-9nona0m7ha/03abecc620fe44d683c9f544e9a36fc7~tplv-9nona0m7ha-image.image)
