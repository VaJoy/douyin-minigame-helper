字节跳动小游戏（以下简称“小游戏”）指提供游戏服务的小程序，如果您是小游戏开发者，需遵守字节小程序《[服务条款](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/operation/agreement/agreement)》、字节跳动小游戏平台《[服务协议](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/agreement-and-norms/agreement)》及字节跳动公布的相关规则、规范、字节小程序全部运营审核规范。除此之外，您还应同时遵守以下文档中的小游戏特别规范内容。
