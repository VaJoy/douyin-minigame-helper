版本审核通过后，开发者点击「**发布**」，小游戏即可发布上线。
如因不符合平台入驻要求无法发布，可咨询平台客服。平台客服咨询路径：[抖音开放平台-控制台](https://developer.open-douyin.com/console?type=2)-我的应用「小游戏 tab」-右下角「开发者助手」。

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/img1651138488763)

## 注意事项
### **设置搜索关键词与分享**
当发布未配置搜索关键词与分享内容版本时，会弹出提示与跳转地址，点击【前往配置】，建议上线前完成该配置。

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/img1651138489190)

如果已有搜索关键词和分享内容，想要查看或进行修改：
- 可以在开发者后台--能力--能力中心--运营能力中的【分享设置】设置：分享标题、分享文案、分享图案。
- 可以在开发者后台--能力--能力中心--运营能力--搜索资源配置中的【搜索关键词】进行搜索标签配置， 另提交的搜索关键词应符合[搜索相关资源配置规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/ability/gain-user/search/)。
### **选择开通虚拟支付/广告能力**
#### 开通内购能力
在开发者后台的功能管理-支付（注意通过主体认证，且资质提交完全，例如版号必须提交），按流程操作申请。

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/img1651138489003)

#### 开通广告服务
开发者在完成相关主体资质认证和对公验证后，即可在后台的**抖音开放平台-商业化-流量主**进行申请开通操作。

![screenshot](https://sf1-cdn-tos.douyinstatic.com/obj/microapp/frontend/docs/images/img1651138489250)
