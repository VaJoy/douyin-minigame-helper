### 普通小游戏
小游戏是一种基于字节跳动产品生态开发的全新游戏应用，无需下载安装即可使用，实现了客户端“点开即玩”的优质用户体验。小游戏具有开发轻便快捷、发布流程简单的特点，同时依托字节跳动生态优势，让小游戏天然具备较强的内容分发能力，支持小游戏开发者快速推广与变现。开发者可以通过小游戏内的广告能力和内购功能来获取收益。

### Unity 小游戏
Unity 小游戏指由 Unity 开发的原生游戏在字节系 APP 中可以免安装、即玩的游戏。Unity 小游戏拥有原生游戏的体验。并且能够连接字节系 APP，使用开放能力，帮助游戏获得较强的内容分发能力，更快速推广与变现。
